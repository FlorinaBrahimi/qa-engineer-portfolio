Accessibility statement

This statement covers the Submission Service demo. It is a portfolio project, not a public service, but it is built and tested as if it were one.

What we aim for

The Web Content Accessibility Guidelines (WCAG) version 2.2, level AA.

How it has been tested

  • Automated WCAG 2.2 A and AA rules (axe-core) on every page state, at desktop and phone widths, on every build.
  • Scripted checks for keyboard-only use, focus order and visibility, reflow at 320 pixels, 200% zoom, increased text spacing, forced-colours mode, reduced motion, error announcement and target size.

Compliance status

No failures are known from the testing above. The service has not had a manual audit, a screen reader assessment by a specialist, or testing with disabled users, so it does not claim conformance with WCAG 2.2 AA.

Known limitations

  • On narrow screens the results table scrolls sideways inside its own region. The region can be focused and scrolled with the arrow keys.
  • Similarity bands use colour as well as the percentage figure. The percentage and the status word carry the same information as text.

Reporting a problem

Raise an issue on the project's GitHub repository, describing the page, what you were trying to do, and the assistive technology you use.
